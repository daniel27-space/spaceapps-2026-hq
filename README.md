Private collaboration HQ for Daniel's NASA Space Apps 2026 entry (Daniel + one teammate). Notes, decisions, plan. No project code here; the real entry starts in a fresh repo on 14 Nov.

How to use: read CONTEXT.md first, check TASKBOARD.md, add an entry to the top of LOG.md after any work.

- CONTEXT.md: goal, dates, rules, roles, AI-tool rules
- TASKBOARD.md: 14-15 Nov board + Sunday handoff/submission checklist
- LOG.md: append-only dated log, newest at top
- decisions/: one file per decision (template inside)
- research/: lessons from the practice MVP, data sources
- runbooks/: GitHub Pages publish, Sun/Earth calc
